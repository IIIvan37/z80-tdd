# Modules

Each module, where it lives, and the decision it hides. Rules: [CODING_STANDARDS.md](../CODING_STANDARDS.md). Vocabulary: [GLOSSARY.md](../GLOSSARY.md).

| Module | Path | Hides |
|---|---|---|
| Public API | `src/index.ts` | Which types and functions a CPC project may use; everything else is internal. |
| Configuration file | `src/configuration-file.ts` | Where the configuration file is (`z80-tdd.config.ts` in the working directory), how it is loaded, which settings it takes and how each is checked, in the file and from a test file, and the default of each (RASM on the PATH, SP `#C000`, 1,000,000 NOPs, Port mask `#FF00`), with a test file's settings over the file's. |
| Program | `src/program.ts` | How an **Assembler**'s output is loaded into 64 KB of memory, which bytes it occupies, and how labels resolve to addresses and ranges, whatever their case (ADR 0006). |
| Run | `src/run.ts` | How a **Routine** is entered and known to have returned (a sentinel return address pushed below SP, reached again with SP back in place), how its options override the SP, NOP limit and Port mask the Program gives it, the Port writes and how a Port read finds the value the test supplied under the Port mask (ADR 0007), how a **Stub** returns to its caller, what it costs and how its calls are recorded, the initial machine state and its checks, the NOP limit, the last 16 instructions it keeps and the failure report built from them, the layout of the flag bits, the bytes the test writes before the Run, the **Memory changes** and which stack bytes they leave out (ADR 0005), and the shape of the frozen result. |
| Matchers | `src/matchers.ts` | The Vitest matchers on a Run (`toChangeOnly`, `toLeaveMemoryUnchanged`), how Vitest learns their types, and the text of their failure messages. |
| Assembler | `src/assembler/` | The interface every assembler implements, the in-memory Assembler that tests use instead of RASM, and the RASM adapter: how it runs `rasm` (on the PATH, or at a given path from the working directory) in a temporary folder on a file that includes the source and saves the 64 KB, how it reads the ORG blocks from the `-map` listing, at the address each is stored at, the labels and EQU symbols from the symbol export, and the errors from the output, and the message when `rasm` is missing. Its contract test runs the real `rasm` on the fixtures in `src/assembler/fixtures/`. |
| NOPs | `src/nops.ts` | The CPC duration of each instruction, prefixed or not, from Madram's tables (ADR 0002, credited in `CREDITS.md`), how a conditional instruction's outcome or a block instruction's repeat is read from the state before it runs, what a chain of prefixes costs, and what a step of a halted CPU costs. |
| CPU | `src/cpu/` | Which Z80 core executes the code (cell80-z80 compiled to WebAssembly, built from `wasm/`, see ADR 0004), how its state maps onto our registers and internal state (WZ, IFF1, IFF2, IM, Q, HALT), the list of register names and widths, and how an instruction is disassembled (cell80's disassembler, in an instance of its own). Its contract test runs SingleStepTests/z80 (`pnpm test:core`). |
